# 🌍 Travel Reviews & Ratings System

An interactive **Travel Reviews & Ratings System** built using **HTML, CSS, and JavaScript**. This project allows users to share their travel experiences, rate destinations or services, and explore feedback from other travelers.

## ✨ Features

* ⭐ Interactive 1–5 star rating system
* 📝 Submit and display user reviews
* 👤 User name and profile information
* 📅 Review date display
* 🔍 Filter reviews by star rating
* 👍 Helpful review button
* 📊 Average rating calculation
* 📈 Rating distribution and statistics
* ✅ Basic form validation
* 📱 Fully responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How It Works

Users can select a rating, write a review, and submit their feedback. The system displays multiple reviews and allows users to filter them based on ratings. Users can also mark helpful reviews, while the platform calculates and displays the overall average rating.
